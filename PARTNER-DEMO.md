## Admin

`/#/admin` with the `ADMIN_EMAIL` / `ADMIN_PASSWORD` environment variables.
Full access: bookings, assignment, refunds, pandit KYC, puja management (full editing +
customised-puja conversion), kundali conditions and mappings, samagri/prasad inventory,
finance, marketing, and the **Demo data** tab (live counts, mock-booking generator,
full RESET with automatic session renewal).

## Suggested 5-minute demo flow

1. **Customer login (30s)** — open the site, Login, tap the *Aarav Mehta* chip,
   Send OTP, enter `123456`.
2. **Kundali with place verification (90s)** — Kundali → fill name/DOB/time →
   type *Delhi* in Place of birth → pick the chip → point out the **Selected Place**
   box: *New Delhi / Delhi, India · 28.6139° N, 77.2090° E · UTC+05:30* — the
   customer verifies the resolved location **before** generating → **Generate Kundali**.
3. **Kundali result (60s)** — lagna/rashi/nakshatra cards, planetary table with
   dignities, dosh cards with "why this was identified" evidence, ranked seva
   recommendations with reasons, havan kunds.
4. **Language toggle (30s)** — click **हिंदी** in the header: the whole result —
   लग्न, राशि, ग्रह स्थिति, दोष विश्लेषण, उपाय, पूजा अनुशंसा — switches to Hindi
   instantly. Click **English** to switch back. No regeneration.
5. **Book a puja (60s)** — Book now on a recommendation → wizard (mode, date/slot,
   pandit, samagri) → demo payment → confirmation.
6. **Pandit portal (30s)** — login as *Pt. Ramesh Sharma* → see the new booking →
   accept → start → complete with checklist.
7. **Admin (30s)** — open `/#/admin` → Dashboard counters moved, the kundali you
   generated is in **Kundali settings → Recent**, the booking is on **Bookings**.
   Optionally: **Demo data → Generate mock bookings** to fill dashboards live.

## Key features to demonstrate

- **Kundali engine**: real sidereal ephemeris (Lahiri), whole-sign houses, Vimshottari
  dasha, navamsa, panchang — no hard-coded charts.
- **Place resolution**: searchable city index with state/country/lat/lon/timezone,
  verified in the form and stored in full.
- **Bilingual experience**: header **English | हिंदी** switch; kundali, dosh analysis,
  remedies, recommendations, puja catalogue and status labels in both languages.
- **Responsible dosh language**: evidence-based, "traditional Jyotish interpretation",
  explicit disclaimers (English and Hindi) — never fear-based selling.
- **Full fulfilment**: home/online/temple modes, pandit assignment + acceptance,
  samagri inventory and delivery, prasad dispatch, refunds, invoices, notifications.
- **Admin control**: every puja, condition→puja mapping, price, commission, coupon —
  editable without code.
- **Customised puja**: public request form → admin queue → convert to a bookable puja.
